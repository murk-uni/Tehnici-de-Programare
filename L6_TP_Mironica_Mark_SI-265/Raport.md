Desfășurarea lucrării

Crearea contului GitHub. Mi-am făcut un cont pe GitHub și am înțeles că el servește la găzduirea și partajarea proiectelor online.

Configurarea Git. Am verificat dacă Git este instalat și am setat numele, adresa de e-mail și ramura principală.

Crearea primului depozit. Pe GitHub am creat depozitul public exercitiu-git, împreună cu fișierul README.md.

Clonarea depozitului. Cu comanda git clone am descărcat depozitul de pe GitHub pe calculatorul meu.

Crearea unui commit. Am scris fișierul salut.py, apoi l-am salvat în istorie cu git add și git commit.

Trimiterea modificărilor. Cu git push am urcat commit-urile de pe calculator pe GitHub.

Sincronizarea depozitului. Am editat README.md direct pe GitHub, iar apoi am adus modificarea pe calculator cu git pull.

Configurarea .gitignore. Am creat fișierul .gitignore prin care Git ignoră folderele .venv/ și __pycache__/.

Verificarea istoricului. Cu git log am parcurs lista commit-urilor, iar cu git diff am văzut ce s-a schimbat într-un fișier înainte de commit.

Crearea celui de-al doilea depozit. Am pornit exercitiu-2 local cu git init, l-am legat de un depozit nou de pe GitHub și l-am publicat cu git push -u origin main.

Concluzie

În cadrul laboratorului am învățat să folosesc Git și GitHub pentru a lucra organizat la un proiect și a-i păstra istoria. Am exersat comenzile de bază cu care salvez modificările, le trimit pe GitHub și le aduc înapoi pe calculator, precum și comenzile prin care văd ce s-a schimbat între versiuni. Am înțeles că Git ajută la ținerea ordinii într-un proiect, la revenirea la o versiune anterioară și la lucrul în echipă, fiindcă fiecare schimbare rămâne înregistrată.
